# v0.1.0 — First Light (Release Candidate)

First implementation from the README-only repository. Three playable missions, drag/touch/keyboard alignment, Gaussian coupling/loss simulation, matched/fixed Mode comparison, progressive hints, four-part Learning Summary, Free Practice, sequential unlocks, independent best Score/Loss, versioned Local Storage and storage-restricted fallback.

Single offline HTML uses no network assets or APIs. Source modules, deterministic build, automated physics/game/persistence/build tests and actual local-file browser QA are included. Release ZIP contains the runnable HTML, README, model documentation, these notes, test summary and a hash list. CI verifies the ZIP and publishes run artifacts.

Status: Release Candidate; feature PR for user review. No main merge or production release tag. Test Summary identifies exactly what was executed. Full-vector/vector polarization effects, gap, angles, evanescent coupling, thermal, bonding and manufacturing yield are not implemented.
